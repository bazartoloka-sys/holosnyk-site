# Голосник — сайт (golosnik.com.ua)

Промо-сайт продукту «Голосник» — Ukrainian-only P2P месенджер із каталогом
фахівців. Розвивається окремо від застосунку, поступово.

Хостинг: Cloudflare Pages. Статичний сайт, без збірки — build command не
потрібен, output directory: `/`.

## Структура

- `index.html` — головна сторінка
- `css/style.css` — стилі (та сама темна палітра, що в застосунку)
- `js/script.js` — інтерактив (3D-колесо вікон — у розробці)
